# Оцінка компетентності експерта 📊

Цей проект — веб-додаток, створений за допомогою **Blazor Web App (.NET 9)**. Він є експертною	системою	визначення	компетентності	експертів	на	базі	аксіоми	незміщеності.

## ✨ Реалізовані функції

* **Динамічне завантаження питань:** Можливість імпортувати опитувальник із JSON-файлу.
* **Інтерактивна форма опитування:** * Введення винятково цілих чисел.
  * Валідація заповненості: кнопка завершення стає активною лише після того, як експерт відповість на всі запитання.
* **Автоматичний розрахунок оцінок:** * Гнучка система нарахування балів з використанням оберненої функції **Smoothstep**, що забезпечує плавне штрафування за відхилення від еталонної відповіді.
  * Розрахунок абсолютної похибки ($x_i - x^*$).
* **Кольорова візуалізація результатів:** Детальна таблиця результатів з автоматичною генерацією кольору для показника похибки (від зеленого до червоного за допомогою CSS HSL-моделі).
* **Експорт та імпорт відповідей:** * Збереження результатів експерта у форматі `.json` на локальний комп'ютер (реалізовано через JS Interop).
  * Завантаження існуючого файлу з відповідями для швидкого перегляду результатів без повторного проходження тесту.

## 🛠 Технології
* C# / .NET 8
* Blazor Web App (Interactive Server Render Mode)
* Bootstrap 5 (UI та стилізація)
* JavaScript Interop (для завантаження файлів з боку клієнта)
